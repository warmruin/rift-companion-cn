# LOL 国服桌面助手设计草案

日期：2026-09-06
状态：用户已确认，已实现；国服实机验证待具备运行中的客户端

## 目标与方案
Windows 桌面应用，采用 Electron + React + TypeScript，中文界面。交付源码、启动说明与 Windows 可执行构建。另一种可选方案为 Tauri，体积更小但增加 Rust 构建依赖；纯网页方案不便直接连接本机客户端，因此首选 Electron。

## 数据可行性
Riot 官方公开 API 路由列表没有中国大陆，不能把 Riot API Key 当作国服战绩接口。首选连接本机登录中的 LOL 客户端 LCU；LCU 不是官方承诺稳定的第三方服务，国服战绩与可见队友身份需要真实客户端验证。未检测到正在运行的 LeagueClient / LeagueClientUx，因此当前不能保证实机查询成功。没有可访问数据时明确显示不可用，不生成假战绩。不识别或还原客户端匿名玩家。

## 功能
1. 英雄推荐：读取可见选人状态，允许手动选择五个敌方英雄、自己的分路与主要对位。展示推荐英雄、层级、对位胜率、样本量及推荐依据；将对位统计与阵容规则评分分开，避免把规则评分当作胜率。排除已选或禁用英雄。敌方位置未知时允许人工修正。
2. 榜单与 counter：为 OP.GG 公开页面编写独立数据适配器，包含来源、版本、地区、段位、获取时间与缓存。页面获取失败时显示缓存时间或数据不可用，并提供原网页入口。OP.GG 非国服统计明确标记为参考，不冒充国服数据；不假设存在公开稳定 API。
3. 队友分析：仅对当前可见、可识别玩家查询最近五场有效对局，展示英雄、模式、日期、胜负、KDA 与近五场胜率。排除重开，优先同模式；不足五场显示实际数量。评分仅表示近期状态，不代表官方段位或长期实力。
4. 评级：近五场胜率为主、KDA 为辅，给出上等马、中等马、下等马及可解释分数；不足三场显示样本不足。具体阈值集中配置，界面可查看评分说明。
5. 连接设置：自动发现本机客户端，支持手动指定 lockfile，显示连接状态、重试、数据更新时间。演示数据如用于开发必须与真实模式明确隔离。

## 架构与错误处理
主进程负责 LCU 凭据、本机 HTTPS 请求、外部数据适配和缓存；渲染进程仅通过限定 IPC 获取结构化数据。凭据不写日志、不传外部站点。只读查询，设置超时、限流、缓存和取消旧请求。客户端断开、匿名、接口受限、样本不足、OP.GG 不可用均有独立状态。

## 验证与验收
验证推荐方向、counter 方向、样本不足、战绩玩家匹配、胜率计算、评分阈值、接口异常及缓存过期。完成类型检查、构建和桌面启动验证。实际国服查询必须在登录中的国服客户端测试；无法进行的实机验证单独披露。不能将模拟响应的测试结果表述为国服接口已验证。
